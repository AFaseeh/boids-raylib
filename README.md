# Boids Simulation with Raylib

A C/C++ implementation of Craig Reynolds' Boids algorithm, simulating the emergent flocking behavior of birds using the Raylib graphics library.

## Getting Started

### Prerequisites
Ensure you have a C/C++ compiler, `make`, and `CMake` installed on your system.

### Build and Run

1. **Configure the project (First time only):**
   ```bash
   make configure
   ```

2. **Build and execute the simulation:**
   ```bash
   make all
   ```
